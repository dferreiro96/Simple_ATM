# ATM Simulator / Cajero Automático

A Python CLI program that simulates an ATM: deposit, withdraw, check balance, and exit.

Un programa de línea de comandos en Python que simula un cajero automático: ingresar, retirar, consultar saldo y salir.

## Features / Funcionalidades

- Start with an initial balance of 1000 / Comenzar con un saldo inicial de 1000
- Deposit money / Ingresar dinero
- Withdraw money (with balance validation) / Retirar dinero (con validación de saldo)
- Check current balance / Consultar saldo actual
- Count the number of operations performed / Contar el número de operaciones realizadas
- Exit the program cleanly / Salir del programa correctamente
- Input validation for invalid options / Validación de entrada para opciones inválidas

## Requirements / Requisitos

- Python 3
